### 👋 About Me

I sit at the intersection of **transportation engineering** and **software development** — I design roads and I write the tools that make designing roads faster.

- 🚧 Transportation Design Technologist at **IMEG** (formerly Rodriguez Transportation Group)
- 🗺️ Daily drivers: **OpenRoads Designer**, **QGIS**, **ArcGIS Pro**, **MicroStation**
- 🚦 Field side: traffic data collection with **Miovision Scout**, TMC/ATR studies
- 🐍 Build side: Python automation, GIS pipelines, and internal AI-assisted tooling
- 🤖 Heavy into **vibecoding** — spec-driven builds with Claude Code, from brainstorm → SPEC.md → shipped app
- 📍 Based in Austin, TX
